# 🎮 E-SPORTS ARENA CHALLENGE

**Projeto acadêmico desenvolvido em Portugol (VisualG).**

## 📌 Sobre o projeto

O **E-Sports Arena Challenge** é um sistema desenvolvido em VisualG para o gerenciamento de equipes e campeonatos de e-sports.

O projeto permite cadastrar jogadores, organizar equipes, acompanhar pontuações, gerenciar campeonatos e consultar rankings, oferecendo uma solução para simular a administração de competições de jogos eletrônicos.

## ⚙️ Funcionalidades

- Cadastro de até **10 equipes**.
- Cadastro de até **6 jogadores por equipe**.
- Suporte para até **60 jogadores no total**.
- Cadastro e gerenciamento de até **5 campeonatos**.
- Consulta das equipes cadastradas e seus respectivos jogadores.
- Registro de pontuações nos campeonatos.
- Classificação e ranking das equipes.
- Geração de relatório de participantes.
- Simulador de infraestrutura e custos.
- Planejamento do projeto.

## 📊 Limites do sistema

| Recurso | Limite |
|---|---:|
| Equipes | 10 |
| Jogadores por equipe | 6 |
| Jogadores no total | 60 |
| Campeonatos | 5 |

## 💻 Tecnologias utilizadas

- **Linguagem:** Portugol
- **Ambiente de desenvolvimento:** VisualG

## 🚀 Como executar

1. Baixe e instale o [VisualG](https://visualg3.com.br/).
2. Abra o arquivo `SPORTS-ARENA-CHALLENGE`.
3. Execute o algoritmo pelo ambiente VisualG.
4. Utilize o menu principal para acessar as funcionalidades disponíveis no sistema.

## 🎓 Objetivo acadêmico

O projeto tem como objetivo aplicar conceitos fundamentais de lógica de programação, utilizando estruturas condicionais, laços de repetição, vetores, procedimentos e organização de dados.

Por meio do desenvolvimento do sistema, busca-se colocar em prática os conhecimentos adquiridos durante o aprendizado de programação, simulando uma aplicação de gerenciamento de equipes e campeonatos de e-sports.
